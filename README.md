# Employee Satisfaction & Demographics Analysis

This project analyzes employee data to identify trends in age and satisfaction across different departments and geographic locations.

## Overview
The analysis compares:
- Average employee age by department
- Satisfaction scores across departments
- Differences between city and suburban employees

## Purpose
The goal of this project was to explore patterns in workforce demographics and engagement, and to identify potential relationships between employee characteristics and satisfaction levels.
